Couleurs

Le système est clair par défaut : le fond principal est blanc ou très pâle, et c'est lui qui domine. Le navy est une couleur de contenu — --primary, pour les titres, le texte et les boutons pleins — et le fond d'une seule bande de rupture par page, jamais celui de la page entière. L'accent marque ce qui est cliquable ou en cours de lecture ; il ne sert jamais de fond à du texte long.

Typographie

Deux familles de titres selon le registre : --font-heading pour les pages publiques destinées aux enfants, --font-display pour les pages pro / à accès protégé. Chez Clap ! Studio, Gaegu et Avenir Heavy ; au Conjugarium, Simply Olive tient les deux rôles. Lexend reste le corps de texte dans tous les thèmes — choisie pour sa lisibilité chez les lecteurs débutants, elle n'est jamais remplacée.

Espacement & rayons

Échelle en rem, multiples de 0.25rem. Les rayons suivent la taille de l'objet : plus la surface est grande, plus le rayon est doux. Tout ce qui est interactif et compact est en pill.

Boutons

Un seul bouton plein par zone visible. Le jaune est réservé à l'action principale ; tout le reste est en ghost. Le hover est toujours un léger scale + éclaircissement, jamais un changement de teinte.

Badges & pills

Le badge jaune qualifie le contenu (type d'œuvre). Le badge ghost qualifie une ressource secondaire. Le badge success confirme un état. Les pills de filtre basculent en jaune plein quand actives.

Séparateurs de section

La signature visuelle : jamais de bord droit entre deux sections de couleurs différentes. La forme vient du thème (--divider-shape) — coulures de peinture chez Clap ! Studio, nuages au Conjugarium. Elle est appliquée en mask-image, donc les couleurs se posent par instance, en CSS pur : plus aucun JavaScript n'est nécessaire.

<!-- --wave-from = section qui précède, --wave-to = section qui suit --> <div class="cl-wave" style="--wave-from:var(--surface); --wave-to:var(--surface-invert)"></div> /* La forme est portée par le thème, jamais par le composant */ :root { --divider-shape: var(--shape-drips); } [data-theme="conjugarium"] { --divider-shape: var(--shape-clouds); }

La densité du motif est réglable par thème, via --divider-repeat : c'est la largeur d'un motif, donc 50% en donne deux sur la largeur. Les coulures gardent 50% ; les nuages, plus larges par nature, passent à 70% pour retrouver la densité du site d'origine. Les deux formes partagent la même convention : un SVG de 1920 unités de large, calé sur son bord bas.

Deux gabarits de page

Le système couvre deux registres. La page publique alterne surface claire, surface sombre et accent, séparés par des .cl-wave, titres en --font-heading. La page protégée reste en surface sombre pleine du haut en bas, sans entête ni pied de page, titres en --font-display — c'est le registre « ressources pro ».

Bande inversée

Le navy n'est plus un fond de page, c'est une rupture : une bande sombre par page, pour le moment fort — le lecteur intégral, une mise en avant. Poser .cl-invert (ou .cl-section-invert) redéclare la rampe de texte, les bordures et les voiles pour tout le sous-arbre. Les composants à l'intérieur sont exactement les mêmes : aucune variante sombre à maintenir.

Thèmes

Les tokens sont en deux couches. Les primitives (--clap-*, --cjg-*) portent les couleurs brutes et ne sont jamais lues par un composant. La couche sémantique (--surface, --accent, --ink…) est la seule que lisent les composants — et donc la seule qu'un thème redéfinit. Basculer le sélecteur en haut de page rejoue toute la documentation dans l'autre thème : aucune classe ni aucun composant ne change.
